## 二、数据分析层

### 2.1 数据分类

| 数据类型 | 频率 | 内容 | 用途 |
|---------|------|------|------|
| **逐笔交易 (Tick)** | 纳秒级 | 每笔成交价、量、方向 | 高频策略、微观结构分析 |
| **限价订单簿 (LOB)** | 微秒级 | 各价位挂单量、订单流 | 做市、订单流预测 |
| **高频TAQ** | 毫秒级 | 报价、交易、卖空指标 | 波动率估计、价差分析 |
| **低频日线** | 日度 | OHLCV、调整收盘价 | 因子模型、组合管理 |
| **基本面数据** | 季度 | 财报、估值指标 | 价值投资、多因子选股 |

### 2.2 高频数据建模（第4章 电子交易中的计量经济学）

#### 核心挑战
1. **市场微观结构噪声**——实际观测价格 = 有效价格 + 噪声
2. **非同步交易**——不同股票交易频率不同，协方差估计有偏（Epps 效应）
3. **离散价格变动**——最小报价单位（如 $0.01）带来的离散性

#### 波动率估计方法

| 方法 | 核心思想 | 适用场景 |
|------|---------|---------|
| 稀疏抽样 | 每5-30分钟取一个样本 | 简单快速，减少噪声 |
| 已实现波动率 (RV) | 高频收益平方和 | 标准方法 |
| 子样本平均 (TSRV) | 多个稀疏网格平均 | 改善RV的噪声偏差 |
| 已实现核估计 | 用核函数加权自协方差 | 稳健性更好 |
| 预平均方法 | 先局部平均再算方差 | 理论最优 |
| 傅里叶方法 | 傅里域估计瞬时波动率 | 可同时估计协方差 |

#### 多资产协方差估计
- **Epps 效应**：频率越高，相关性估计越接近0（因非同步）
- **解决方法**：傅里叶方法、已实现核、QMLE

### 2.3 限价订单簿 (LOB) 分析（第5章）

#### LOB 核心特征
- **价格调整机制**：限价单被市价单吃掉后，价格向反方向移动
- **交易量不平衡**：
  - 定义：买入侧挂单总量 - 卖出侧挂单总量
  - 正值 → 卖方占优（价格可能下跌）
  - 负值 → 买方占优（价格可能上涨）
- **订单流毒性**：信息不对称程度（VPIN 指标可参考）

#### LOB 建模方法
1. **多元点过程 (Hawkes 过程)**——自激励效应，一个订单到来增加后续同类订单的概率
2. **机器学习分析**——用历史LOB状态预测短期价格方向
3. **排队论建模**——把订单簿看作多个队列，用连续时间马尔可夫链（CTMC）分析

## 三、统计模型与方法（第2章）

### 3.1 股票价格特征

| 特征 | 描述 |
|------|------|
| **非正态分布** | 尖峰厚尾，极端值比正态分布更常见 |
| **收益自相关** | 短期轻微正相关，长期负相关 |
| **波动率集聚** | 大波动后跟着大波动 |
| **跳跃** | 价格不连续变动（消息冲击） |

### 3.2 时间序列模型演进

```
随机游走 → ARIMA → GARCH → 鞅回归
   ↓          ↓        ↓        ↓
 布朗运动   线性ARMA 波动率   条件均值+方差
                        时变    联合建模
```

### 3.3 现代投资组合理论

#### 多因子定价模型（Fama-French 框架）
- **市场因子 (MKT)**：全市场超额收益
- **规模因子 (SMB)**：小盘股 - 大盘股
- **价值因子 (HML)**：高账面市值比 - 低账面市值比
- **动量因子 (MOM)**：过去赢家 - 过去输家

#### Black-Litterman 模型
- 结合先验（市场均衡）和观点（分析师判断）
- 解决 Markowitz 对输入参数过于敏感的问题

#### NPEB 方法（非参数经验贝叶斯）
- 用 Bootstrap 重抽样估计参数不确定性
- 在优化中自动惩罚极端权重
- 比传统均值-方差更稳健

### 3.4 有效市场之外的策略

| 策略类型 | 核心理念 | 时间跨度 |
|---------|---------|---------|
| **动量策略** | 过去涨的继续涨 | 3-12个月 |
| **配对交易** | 两只高度相关股票的价差回归均值 | 数天-数周 |
| **逆向投资** | 过度反应后反转 | 1-3年 |
| **价值投资** | 买入被低估的资产 | 长期 |
| **统计套利** | 多空组合的均值回归 | 高频-日内 |

## 四、积极型投资组合管理（第3章）

### 4.1 Alpha 与 Beta 框架

```
组合收益 = Beta × 市场收益 + Alpha + 残差
  ↑            ↑                ↑
  被动     市场暴露          主动管理能力
```

- **Alpha 来源**：
  1. 信息优势（比别人早知道）
  2. 分析优势（比别人更能解读数据）
  3. 执行优势（比别人更快的交易）
- **奇异 Beta**：不是传统市场因子，而是另类风险暴露（如波动率、流动性、信用）

### 4.2 交易成本建模

交易成本 = 显性成本 + 隐性成本

| 成本类型 | 内容 | 影响 |
|---------|------|------|
| 佣金 | 经纪商费用 | 固定成本 |
| 买卖价差 | 买入价 - 卖出价 | 主要成本 |
| 市场冲击 | 大单推动价格不利变动 | 非线性增长 |
| 延迟成本 | 等待最佳时机错失的收益 | 时间成本 |

### 4.3 多期投资组合优化

- **Samuelson-Merton 模型**：连续时间随机控制理论
- **带交易成本的优化**：最优策略是不频繁再平衡（避免磨损）
- **波动率脉动**：高波动时期应减少头寸
- **参数不确定性**：多期环境下更难精确估计

## 五、最优执行（第6章）

### 5.1 单资产最优执行

**核心问题**：如何在 T 时间内卖出 S 股，使总成本最小？

**Almgren-Chriss 框架**：
```
总成本 = 市场冲击成本 + 时间风险成本
              ↑                  ↑
        交易越快成本越高     等待越久价格越不确定
```

- **最优解**：VWAP/TWAP 策略的数学基础
- **确定性策略**：按最优速度持续卖出
- **随机策略**：根据市场情况动态调整

### 5.2 价格影响模型

- **临时影响**：仅影响当笔交易，之后恢复
- **永久影响**：改变市场均衡价格
- **传导性价格影响**：在一个交易所的交易影响另一个交易所的价格

### 5.3 LOB 最优执行
- 利用 LOB 形状信息优化下单路径
- 块状 LOB 有解析解
- 考虑自身订单对 LOB 的影响

## 六、做市策略（第7章）

### 6.1 核心模型

| 模型 | 核心思想 |
|------|---------|
| **Ho-Stoll 模型** | 做市商在库存风险和时间风险之间权衡 |
| **Avellaneda-Stoikov** | 基于 HJB 方程的最优报价决策 |
| **脉冲控制模型** | 用限价单和市价单的组合控制库存 |

### 6.2 做市商决策
- **最优买卖价差** = 逆向选择成本 + 库存持有成本 + 订单处理成本
- **库存管理**：头寸偏离目标时调整报价
- **报价更新**：每笔交易后根据市场条件更新

### 6.3 智能订单路由 (SOR)
- 在多个交易所之间拆分订单以获取最佳价格
- 暗池交易：信息不透明，需要探索-开发权衡
- **Kaplan-Meier 估计**：估计暗池的成交概率
- **贪心算法**：每次把订单分配给成交概率最高的交易所

## 七、信息学与基础设施（第8章）

### 7.1 量化策略系统架构

```
┌──────┐     ┌──────────┐     ┌──────────┐     ┌──────┐
│ 市场  │────▶│ 市场数据  │────▶│ Alpha    │────▶│ 订单  │
│ 数据  │     │ 处理单元  │     │ 引擎     │     │ 管理  │
└──────┘     └──────────┘     └──────────┘     └──────┘
                  │                 │               │
                  ▼                 ▼               ▼
              解码行情          策略运算        发送/撤销订单
              构建LOB          生成信号        跟踪订单状态
```

### 7.2 策略支柱组件
1. **市场数据处理**：解码行情 → 构建 LOB → 计算指标
2. **Alpha 引擎**：价格预测 → 生成信号 → 决定买卖
3. **订单管理**：验证订单 → 发送 → 跟踪 → 撤销

### 7.3 基础设施关键点
- **订单网关**：连接交易者的通道，负责验证和路由
- **匹配引擎**：按照价格-时间优先规则匹配订单
- **市场数据广播**：FIX/FAST 协议（纽交所/欧交所）、ITCH 协议（纳斯达克）
- **主机托管**：服务器放在交易所附近，减少延迟

## 八、风险管理（第8章）

### 8.1 操作风险
| 风险类型 | 描述 | 防范措施 |
|---------|------|---------|
| 系统故障 | 硬件/软件崩溃 | 冗余备份，监控告警 |
| 网络延迟 | 行情或订单延迟 | 托管，直连 |
| 订单错误 | 价格/数量输错 | 风控过滤，最大订单限制 |
| 合规风险 | 违反交易规则 | 合规检查，交易报备 |

### 8.2 策略风险
| 风险类型 | 描述 | 防范措施 |
|---------|------|---------|
| 模型风险 | 模型假设不成立 | 样本外检验，压力测试 |
| 过拟合 | 策略在历史数据上表现好但实战亏损 | 交叉验证，正则化 |
| 流动性风险 | 市场条件变化导致无法平仓 | 头寸规模控制 |
| 尾部风险 | 极端事件（如熔断） | 止损，VaR 限制 |
| 参数漂移 | 最优参数随时间变化 | 定期重估计 |

### 8.3 风控指标速查
- **最大订单金额**：限制单笔交易规模
- **日最大亏损**：达到后停止交易
- **最大持仓**：限制总风险暴露
- **最大杠杆**：限制借贷比例
- **订单频率限制**：防止系统过载

## 九、策略评估方法论

### 9.1 样本内 vs 样本外
- 永远不要在回测优化过的数据上评估策略好坏
- 方法：时间序列交叉验证（前推验证）

### 9.2 多重检验修正
- 尝试 1000 个策略，即使全是随机，也有 50 个在 5% 显著性水平下"显著"
- **Bonferroni 校正**：显著性水平 ÷ 测试次数
- **FDR 控制**：控制假发现率

### 9.3 常用绩效指标

| 指标 | 公式 | 含义 |
|------|------|------|
| **夏普比率** | (收益 - 无风险利率) / 标准差 | 单位风险回报 |
| **信息比率** | α / 跟踪误差 | 主动管理能力 |
| **最大回撤** | 峰值到谷底的最大跌幅 | 最坏情况 |
| **Calmar 比率** | 年化收益 / 最大回撤 | 收益/风险替代 |
| **胜率** | 盈利交易 / 总交易数 | 策略准确度 |
| **盈亏比** | 平均盈利 / 平均亏损 | 单次盈亏幅度 |
