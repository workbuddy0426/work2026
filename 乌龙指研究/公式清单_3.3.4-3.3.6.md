# 3.3.4 至 3.3.6 公式清单

## 3.3.4 多期均值-方差再平衡

### 公式①：均值-方差替代法
```
U ≈ E[R] − λ × Var[R]
```
U=满足感，E[R]=预期收益，Var[R]=风险，λ=风险厌恶系数

### 公式②：近似动态规划(ADP)
```
Vₜ(xₜ) = max { cₜ(xₜ, uₜ) + E[Vₜ₊₁(xₜ₊₁)] }
```
Vₜ=价值函数，xₜ=当前状态，uₜ=决策，cₜ=即时收益，E[Vₜ₊₁]=未来价值期望

## 3.3.5 含交易成本的动态优化

### 公式③：超额收益的因子分解
```
˜Rₜ₊₁ = Bfₜ + εₜ₊₁
```
下一期的超额收益 = 因子载荷B × 当前因子值fₜ + 随机误差ε

### 公式④：因子自回归
```
fₜ₊₁ = (I − Φ)fₜ + wₜ₊₁
```
因子随时间的变化，服从VAR模型，I−Φ控制回归速度

### 公式⑤：总优化目标
```
max E[ Σ ρᵗ ( uₜᵀ˜Rₜ₊₁ − γ uₜᵀΣ uₜ − (Δuₜ)ᵀΛ Δuₜ ) ]
```
三项拆解：
- uₜᵀ˜Rₜ₊₁：持仓×收益 = 总收益
- γ uₜᵀΣ uₜ：风险厌恶×组合风险 = 风险惩罚
- (Δuₜ)ᵀΛ Δuₜ：调整量×成本矩阵×调整量 = 交易成本惩罚

### 公式⑥：关键假设
```
Λ = λΣ
```
交易成本矩阵Λ 与风险矩阵Σ 成比例 → 使问题有解析解

## 3.3.6 参数不确定性

### 公式⑦：Brennan的模型设定
```
dPₜ/Pₜ = μ dt + σ dBₜ
```
风险资产价格变动 = 未知的预期收益μ + 已知的波动率σ × 布朗运动

### 公式⑧：Kalman-Bucy滤波更新
```
dmₜ = (vₜ / σ²) (dPₜ/Pₜ − mₜ dt)
```
μ的新估计mₜ = 旧估计 + Kalman增益 × (实际观测 − 预测值)
vₜ越大(不确定越大)→更新幅度越大

### 公式⑨：Cvitanić多资产扩展
```
µᵢ − r = αᵢ + βᵢ(µ₀ − r)
```
每个资产的超额收益 = 个股αᵢ + βᵢ × 市场超额收益
θ = (θ₀, ..., θₘ)ᵀ 的先验 → 后验通过Kalman-Bucy滤波更新
